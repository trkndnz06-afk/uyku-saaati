Privacy Policy – Uyku Kanali Otomasyon

Last updated: 21 November 2026

Uyku Kanali Otomasyon is a personal tool operated by the owner of the Uyku Saaati YouTube channel. It is used only by the channel owner.

YouTube API Services

Uyku Kanali Otomasyon uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Data accessed

With the owner's consent, the tool uses Google OAuth to access the owner's own YouTube account through the YouTube Data API, solely to upload videos, set their titles, descriptions, thumbnails and chapters, and read basic channel information and the status of the owner's own uploads.

Storage and sharing

No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Data retention and deletion

The OAuth token (token.json) is kept only on the owner's own computer. It can be deleted at any time by removing token.json, and access can be revoked at https://myaccount.google.com/permissions or via Google security settings at https://security.google.com/settings/security/permissions. No YouTube data is stored beyond the video IDs of the owner's own uploads.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
