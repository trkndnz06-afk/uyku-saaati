Privacy Policy – Uyku Kanali Otomasyon

Last updated: 21 November 2026

Uyku Kanali Otomasyon is a personal tool operated by the owner of the Uyku Saaati YouTube channel. It is used only by the channel owner.

Data accessed

With the owner's consent, the tool uses Google OAuth to access the owner's own YouTube account through the YouTube Data API, solely to upload videos, set their titles, descriptions, thumbnails and chapters, and read basic channel information.

Storage and sharing

The OAuth token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
